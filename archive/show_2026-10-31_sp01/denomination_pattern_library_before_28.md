**📓f finding: Performative mode dominance.** Thirteen of the twenty-four patterns formally entered in this document are performative. This is not an artifact of sampling — it reflects the structural reality that American political discourse operates primarily through institutional mediation, and institutional actors' primary tool is performance. The system rewards performing engagement over engaging substance. This finding should be flagged for 📓g: if the encoding detects performative denomination far more often than other modes, it is probably calibrated correctly, not biased.

## The Library

### Pattern 1 — Preemptive Denomination Foreclosure

- **Source:** 📓e1 Event 1
- **Mode:** Defensive
- **Stage:** 2→3 (frame consolidated enough for pre-evaluation dismissal; trending substance replacement because the object never enters engagement)
- **Description:** Classifying a position as denominated before evaluating its substance, making evaluation unnecessary.
- **Ghost slider rendering:** Opposing position dims before it fully appears. The user sees the position pre-classified rather than evaluated. The object is visible behind the classification overlay but inaccessible through it.
- **Diatribe range:** 40–65
- **Cross-references:** Mirror of 📓e4's "progressive totalization" (Pattern 1 applied at scale); see also #20 (cultural diagnosis) which uses a different frame to achieve same foreclosure.

### Pattern 2 — Performative Institutional Denomination

- **Source:** 📓e1 Events 2, 3
- **Mode:** Performative
- **Stage:** 3 (substance replacement — institutional actors perform the opposite of their institutional action)
- **Description:** Participating in institutional sabotage then voting the opposite way. The institutional actor's public position and institutional behavior directly contradict each other.
- **Ghost slider rendering:** Opposing position splits — stated position visible on one layer, institutional action contradicts it on another. The ghost renders the gap between performance and action.
- **Diatribe range:** 50–65
- **Cross-references:** Inverse of #23 (which performs *insurgency* while serving institutional interests; #2 performs *loyalty* while sabotaging institutional position). See also #19 (democratic performance masking capture) for the collective version.

### Pattern 3 — Destroying Functional Mechanism While Claiming to Want Better

- **Source:** 📓e1 Events 4, 10
- **Mode:** Performative
- **Stage:** 3 (substance replacement — destruction framed as improvement; the mechanism disappears behind the claim of superior alternative)
- **Description:** The "maximum pressure" / "free nuclear fuel forever" pattern. A functional mechanism (JCPOA, diplomatic framework) is destroyed with the stated justification that a better one will replace it. The replacement never materializes. The destruction was the goal.
- **Ghost slider rendering:** The functional object (e.g., JCPOA) fades while the claim ("better deal") takes its visual place. Over time, the replacement never solidifies — the ghost shows an empty space where the claimed alternative should be.
- **Diatribe range:** 55–75
- **Cross-references:** Structural twin of #21 (procedural sabotage) — both destroy mechanisms rather than engaging substance. #3 destroys policy mechanisms; #21 destroys democratic mechanisms.

### Pattern 4 — Defensive Denomination Through Non-Engagement (Single Instance)

- **Source:** 📓e1 Event 6
- **Mode:** Defensive
- **Stage:** 2 (frame consolidation — frame solid enough to make engagement unnecessary; no active substance replacement yet; the object is simply ignored)
- **Description:** Unable to praise, criticize, or engage, so saying nothing. The Abraham Accords silence pattern — a genuine achievement by an opponent that the subject's frame cannot accommodate, producing a void.
- **Ghost slider rendering:** Opposing position exists and is visible, but the scored position shows a void — no engagement to render. The ghost shows what *would* be there if engagement occurred.
- **Diatribe range:** 40–55
- **Cross-references:** Temporal expression = #15 (compounding version). When #4 recurs, it becomes #15. The encoding must track recurrence count. See also #13 (denial mode) which is the active version — #4 is passive absence; #13 is active refusal.

### Pattern 5 — Conspiratorial Boundary Enforcement

- **Source:** 📓e1 Event 8
- **Mode:** Conspiratorial
- **Stage:** 3→4 (reclassifying disagreement as enemy allegiance = substance replacement trending toward totalization)
- **Description:** Reclassifying political disagreement as evidence of hidden allegiance to a monstrous enemy. Structurally identical on left (Clinton-Gabbard) and right (QAnon recruitment). The person disappears into a category.
- **Ghost slider rendering:** Opposing position transforms from "person with different view" to "agent of hidden enemy." The person-marker on the legibility map is absorbed into a category marker. Individual features become invisible.
- **Diatribe range:** 65–80
- **Symmetry test:** Must score within 5 points regardless of X-axis side. Calibration: Clinton-Gabbard (75–80) ≈ equivalent QAnon mechanism (75–80). ✓
- **Cross-references:** Mechanism that, deployed at scale or absorbed into culture, produces #12 (conspiratorial totalization) as terminal condition. Escalation path: #5 → #12. See also #11 (institutional acknowledgment neutralizing content) which uses the same "pursuit = enemy allegiance" structure but through institutional authority rather than conspiratorial narrative.

### Pattern 6 — Institutional Denomination Through Question Selection

- **Source:** 📓e1 Event 8
- **Mode:** Performative
- **Stage:** 2 (frame consolidation — the frame determines what question is legible; the wrong question makes the right answer impossible)
- **Description:** Media/institutional framing that determines which question gets asked, which determines the answer. Appears neutral but the frame does the analytical work before anyone makes an argument.
- **Ghost slider rendering:** The object is visible but the angle of approach makes key features invisible — like lighting a sculpture from one angle that casts the critical features in shadow. Rotate the light (change the question) and the object looks completely different.
- **Diatribe range:** 35–55
- **Cross-references:** Operates earlier in the denomination sequence than most patterns. Often the *precondition* for #1 (preemptive foreclosure) — if the question is framed to make one answer feel conspiratorial, #1 follows naturally. See also #10 (institutional reclassification) which operates on definitions rather than questions.

### Pattern 7 — Z-Suppression Through Definitional Retreat (Individual)

- **Source:** 📓e1 (captive dreamer satellite)
- **Mode:** Defensive
- **Stage:** 2→3 (narrowing definitions = frame consolidation hardening; when definition shrinks enough, the original promise/prediction is replaced by narrowed version)
- **Description:** An individual actor narrowing the definition of a prediction or promise to avoid falsification. The Z-gap between promise and outcome shrinks not because reality changed but because the measuring instrument was recalibrated by the person who made the promise.
- **Ghost slider rendering:** The Z-gap visually shrinks as the definition narrows. The ghost shows the original definition as a fading outline around the narrowed one, making the retreat visible.
- **Diatribe range:** 55–70
- **Cross-references:** Individual-scale version of #10 (institutional definitional reclassification). #7 is correctable by pointing at the record; #10 rewrites the record. Same mechanism, radically different enforcement power.

### Pattern 8 — Z-Suppression Through Historical Revision

- **Source:** 📓e1 (Tim Pool satellite)
- **Mode:** Denial
- **Stage:** 3 (substance replacement — actual history replaced with revised version that eliminates the gap)
- **Description:** Rewriting the past to eliminate the gap between promise and outcome. Unlike #7 (which narrows future-facing definitions), this operates retroactively — the past itself is revised to match the present.
- **Ghost slider rendering:** The timeline itself changes. Past positions shift to match current outcomes. The ghost shows the original timeline as a shadow behind the revised one.
- **Diatribe range:** 60–75
- **Cross-references:** Retroactive complement to #7 (which narrows forward; #8 revises backward). Both suppress Z-axis gaps; together they represent a complete Z-suppression toolkit — shrink the promise AND rewrite the history.

### Pattern 9 — Performative Glorification

- **Source:** 📓e1 Event 10
- **Mode:** Performative
- **Stage:** 3 (substance replacement — spectacle replaces engagement with military/political substance)
- **Description:** Operation names, staged photos, historical cosplay — treating military or political action as aesthetic spectacle. The spectacle IS the content; the substance (consequences, costs, strategic rationale) is invisible behind it.
- **Ghost slider rendering:** The political object disappears behind aesthetic presentation. The ghost renders the object in full substantive complexity; the user's slider shows only the spectacular surface. The gap between the two is the pattern's diagnostic signal.
- **Diatribe range:** 55–75
- **Cross-references:** Related to #19 (democratic performance masking capture) — both are surface/substance splits. #9 uses aesthetic spectacle; #19 uses democratic framing. See also #18 (honesty that raises Diatribe) as the inverse — when the spectacular surface is dropped and the substance appears, the Diatribe paradoxically increases because the substance is worse than the performance.

### Pattern 10 — Institutional Definitional Reclassification

- **Source:** 📓d (Nuland biolabs exchange)
- **Mode:** Performative
- **Stage:** 3 (substance replacement — bureaucratic language replaces the object; "biological research facilities" replaces "biolabs")
- **Description:** Institutional-scale relabeling performed under authority (testimony, official statements, fact-checks) that makes the old terminology — and therefore the old questions — feel conspiratorial to use. The reclassification holds because institutional credentialing makes further inquiry seem like paranoia.
- **Ghost slider rendering:** The object's label changes. The old label (and therefore old questions about the object) are pushed into the conspiratorial rendering zone. The ghost shows the original label as still valid, making the reclassification visible.
- **Diatribe range:** 65–80
- **Cross-references:** Institutional-scale version of #7 (individual definitional retreat). #7 can be falsified by anyone with a memory; #10 rewrites the evidentiary standard itself. See also #11 (institutional acknowledgment neutralizing content) — same institutional authority mechanism, different operation (#10 relabels; #11 acknowledges-then-neutralizes).

### Pattern 11 — Institutional Acknowledgment That Neutralizes Its Own Content

- **Source:** 📓d (51 intelligence officials letter; Nuland testimony)
- **Mode:** Performative + Defensive (dual-mode)
- **Stage:** 3 (substance replacement — acknowledgment performs openness while framing prevents pursuit)
- **Description:** Partially acknowledging a real phenomenon while constructing a frame that makes further pursuit evidence of enemy allegiance. "Yes, but..." structure where the "but" structurally prevents the "yes" from producing consequences. The 51 officials' letter acknowledges the laptop's existence while framing it as Russian operation; Nuland acknowledges facilities while framing inquiry as Russian propaganda.
- **Ghost slider rendering:** Object briefly appears in full clarity (the acknowledgment), then immediately dims as the framing wraps around it. The ghost holds the moment of clarity — the user can see what the object looked like before the neutralization.
- **Diatribe range:** 65–80
- **Cross-references:** Same institutional authority mechanism as #10 but different operation: #10 relabels the object; #11 acknowledges then neutralizes it. Both use the #5→#12 escalation path (pursuit = enemy allegiance) but through institutional rather than conspiratorial channels.

### Pattern 12 — Conspiratorial Object Destruction Through Totalization

- **Source:** 📓d (Pizzagate endpoint; QAnon totalization)
- **Mode:** Conspiratorial
- **Stage:** 4 (totalization — terminal state; the object has vanished entirely into the totalizing narrative)
- **Description:** Totalizing narrative absorbs all evidence, discrediting legitimate inquiry. The object (actual elite misconduct, actual policy problems) disappears into an unfalsifiable framework that makes engagement with substance unnecessary because the framework already provides all answers.
- **Ghost slider rendering:** No original object visible. The entire view is the totalizing framework. All new information is immediately absorbed into the existing narrative. The ghost shows what the original objects would look like outside the totalizing frame — but from inside the frame, the ghost's rendering looks naive or complicit.
- **Diatribe range:** 70–85
- **Capacity for surprise:** Destroyed. This is the encoding's most fundamental diagnostic marker for Stage 4.
- **Cross-references:** Terminal state of #5 (boundary enforcement). Escalation path: #5 → #12. The gradient framework from 📓d (proportionate → disproportionate → conspiratorial) is the trajectory that ends here. See also #13 (denial mode) for the left-side mirror that arrives at the same structural position through defensive refusal rather than totalizing narrative.

The evidence is not absorbed into a totalizing counter-narrative (#12) but simply denied standing. The 📓d symmetry finding: "the right totalizes, the left denies, but both destroy the object equivalently." See also #4 (defensive non-engagement) — #4 is passive absence; #13 is active refusal.

### Pattern 16 — Z-Gap by Architectural Design

- **Source:** 📓e4 Event 3 (IIRIRA)
- **Mode:** Performative (structural)
- **Stage:** 3 (substance replacement — the mechanism's stated purpose has been replaced by its actual function; the gap is a feature, not a bug)
- **Description:** Statutory or institutional architecture that structurally produces the problem it claims to address. IIRIRA creates conditions that generate unauthorized immigration while criminalizing it. The Z-gap is load-bearing — the system depends on the gap's persistence.
- **Ghost slider rendering:** The object appears as a closed loop — the "solution" and the "problem" are the same mechanism viewed from different angles. The ghost breaks the loop, showing the causal chain from mechanism to problem it generates.
- **Diatribe range:** 70–80
- **Cross-references:** Mechanism-level, not actor-level. Denomination is *architectural* rather than personal. Related to #3 (destroying functional mechanism) but inverted: #3 destroys something that works; #16 builds something that fails by design. See also 📓e4's Z-eruption concept — when #16's load-bearing gap collapses, the eruption produces the worst outcomes of both the gap and the closure.

### Pattern 17 — Denomination Catastrophe

- **Source:** 📓e4 Event 6 (escalator speech)
- **Mode:** Reactionary
- **Stage:** 3→4 (real capital frozen permanently in vehicle; substance replacement solidifying into totalization)
- **Description:** Real informal capital (genuine border community suffering, real economic grievance) denominated into a vehicle (racialized threat narrative) that freezes the capital permanently, foreclosing the cross-axis exchange that would make resolution possible. The vehicle doesn't just capture the concern — it makes the concern unreachable from the other side.
- **Ghost slider rendering:** Genuine concern visible underneath but encased in the vehicle — like amber preserving an insect. The original substance is visible but inaccessible. The ghost shows what the concern would look like if extracted from the vehicle (the inverse grammar's substance extraction operation).
- **Diatribe range:** 65–80
- **Cross-references:** The only pattern mapped to the reactionary mode. Reactionary politics = negation of the other's subjectivity (💹 A definition), and denomination catastrophe negates the other's access to the underlying concern by encoding it in a vehicle they cannot approach without appearing to endorse the vehicle. See 🕊️ I's three denomination tests — #17 fails all three (substance replaced, traversal destroyed, deliberation foreclosed).

### Pattern 18 — Honesty That Raises Diatribe

- **Source:** 📓e4 (Rubio stated priorities, 2026)
- **Mode:** Performative (inverse — the prior moral justification was the performance; the honesty breaks it)
- **Stage:** 3 (substance replacement *revealed* — candor shows that the stated moral purpose was never the operational substance)
- **Description:** An actor's candid statement reveals institutional priorities that contradict the moral basis of an operation. Rubio: "while restoring democracy remains a long-term goal, coercing the current government to address U.S. security, migration, and energy concerns is the immediate aim." The honesty increases the Diatribe because it confirms that the prior moral framing was performative.
- **Ghost slider rendering:** The moral justification layer peels away, revealing institutional priorities underneath. The ghost renders both layers simultaneously — the prior performance and the revealed substance. The gap between them IS the pattern.
- **Diatribe range:** 70–85
- **Cross-references:** Inverse of #9 (performative glorification, which adds spectacular surface over substance; #18 removes the surface). Paradox: the honest moment produces the highest Diatribe score for the revealed institution, even though the individual act of honesty is itself low-Diatribe. The encoding must distinguish the actor's candor-Diatribe from the institution's revealed-priority-Diatribe.

### Pattern 20 — Cultural Diagnosis Masking Economic Mechanism

- **Source:** 📓e2 Event 7 (Vance "childless cat ladies")
- **Mode:** Defensive (bilateral)
- **Stage:** 2→3 (frame consolidation — cultural frame prevents economic mechanism from being seen; trending substance replacement as the cultural narrative becomes the whole explanation)
- **Description:** Accurate cultural observation → values attribution → suppression of economic cause. Operates bilaterally. The right codes family formation as cultural/values issue; the left codes it as women's autonomy issue. Both framings suppress the economic mechanism (housing costs, childcare costs, wage stagnation) that actually drives the trend. Neither side can see the economic cause because their respective cultural frames are doing all the interpretive work.
- **Ghost slider rendering:** Economic mechanism visible but occluded by cultural framing overlay from both sides simultaneously. The ghost strips both cultural frames, revealing the shared economic substrate. This is the inverse grammar's strongest worked example in 📓e2.
- **Diatribe range:** 45–65
- **Cross-references:** The bilateral character is the key diagnostic — when the same masking operates on both X-axis sides, the masked object (economic mechanism) becomes doubly inaccessible. Related to #1 (preemptive foreclosure) — #20 provides the frame that makes #1 feel justified on both sides. See 📓e2's lens case flag for 🔍 E: the emotional dimension requires the encoding to register what neither the policy-analysis nor feminist lens alone can see.

### Pattern 22 — Retroactive Democratic Nullification

- **Source:** 📓e2 Event 8 (Missouri repeal strategy)
- **Mode:** Performative
- **Stage:** 3→4 (using democratic form to negate democratic substance — the most advanced form of performative institutional denomination; attacks legitimacy of mechanism from within)
- **Description:** Using democratic form (ballot measure) to negate democratic substance (prior ballot result). The form/substance split is the diagnostic: democratic form as vehicle for anti-democratic substance. When a ballot measure is designed to reverse a previous ballot measure's effect through procedural restructuring rather than substantive re-argument, it attacks the democratic mechanism's credibility.
- **Ghost slider rendering:** Prior democratic result visually dissolving as new measure overwrites it. The democratic form is visible and intact but the democratic substance is being consumed from within. The ghost preserves the prior result and shows the nullification operation in progress.
- **Diatribe range:** 80–90
- **Cross-references:** Internal complement to #21 (which sabotages from outside the democratic form; #22 sabotages from within). Together #21 and #22 represent a complete toolkit for attacking democratic mechanisms — external (change the rules) and internal (use the rules against themselves). See 📓e2 structural principle #6 (meta-binary migration) — #22 signals that contestation has shifted from policy substance to democratic infrastructure itself.

### Pattern 27 — Performative Y-Crossing

- **Source:** J_diagnostic_v1.md (March 7, 2026) — dia•gnostic instrument development
- **Mode:** Performative
- **Stage:** 2 (frame consolidation — position held for function not conviction; no active substance replacement because the position is never genuinely occupied)
- **Description:** Stated position crosses the Y-axis under identifiable political pressure, producing a formal ledger entry (vote, statement, co-sponsorship) without producing a wake in the informal ledger. Actor returns to prior Y-position when pressure lifts. Detectable only through longitudinal dual-ledger analysis. Instrumental denomination — mid-Diatribe, low displacement.
- **Ghost slider rendering:** Y-axis crossing visible on the formal layer; informal layer shows no corresponding movement. The ghost renders the crossing as a dotted line (tentative, weightless) rather than a solid trajectory. When pressure lifts, the formal line retracts; the informal layer was never disturbed.
- **Diatribe range:** 25–50. Low heat, structurally dishonest. Quiet hollowness rather than tribal denomination.
- **Distinction from #4/#15:** Involves a formal crossing that non-engagement patterns do not. The surface behavior is compliant; the hollowness is in the informal record. #4 is absence (no engagement at all); #15 is compounding absence; #27 is *present but empty* — the engagement exists on paper but carries no wake.
- **Methodology:** See J_diagnostic_v1.md — dia•gnostic instrument, Z-gap correlation with political cost, the Wake.
- **Calibration case:** War powers senator voting under base pressure, no follow-on coalition-building, no floor speeches outside news cycle, return to prior hawkish position within one news cycle. Formal ledger records crossing; informal ledger shows no wake.
- **Cross-references:** Distinguishable from Migratory Diatribe (Rubio 25→60→80) by shape — crossing is temporary and reversible; migration is continuous and unidirectional. Related to #2 (performative institutional denomination) — both involve formal/informal divergence, but #2 is institutional action contradicting public position; #27 is public position contradicting institutional identity.

## Calibration Principles Established in This Session

### Principle 1 — Individual/Mechanism Floor Distinction

**Individual actors can score lower on the Diatribe than institutional mechanisms, because individuals can achieve zero performative dimension while institutional mechanisms always carry procedural overhead.**

The Diatribe's absolute floor (0–10) is reserved for individuals and direct human experience: children's suffering, displaced persons experiencing events, Gary Webb, Rand Paul, Janet Murguía. The cleanest *mechanisms* start around 15–20 (Kansas ballot initiative at 20, ACLU cross-administration litigation at 15, DACA at 20–25).

**Derivation:** Cross-domain spot-check of Rand Paul (Diatribe 10 in both 📓e1 and 📓e4) against Kansas (Diatribe 20 in 📓e2). The 10-point gap is principled: Rand Paul's engagement has zero denomination dimension — proportionate, falsifiable, costly. Kansas as a mechanism compressed denomination to near-zero, but the surrounding discourse (the ballot initiative existing because institutional actors failed to engage substance through normal channels) creates a floor above zero. The event is clean; the conditions that produced it are not. At the low end of the scale, surrounding context creates a floor that purely principled individual actors can get beneath.

**Implication for 🔧 J:** The agent should expect individual-actor scores to reach lower Diatribe values than mechanism scores. If a mechanism scores below 15, the calibration should be questioned. If an individual scores above 15 while maintaining full capacity for surprise and zero performative dimension, the calibration should also be questioned.

### Principle 2 — Reactionary Mode Singularity

**Reactionary denomination is structurally simpler than other modes — one mechanism (negation of the other's subjectivity) with high valence across contexts.**

The 💹 A definition (reactionary politics as negation of the other's subjectivity) is a single operation that attaches to whatever vehicle is available. It doesn't diversify into multiple patterns because the mechanism is always the same: deny the other's standing as a subject. The escalator speech does it through racialization, dispensationalism through prophetic function assignment, megachurch architecture through erasure of the other's tradition. One operation, many vehicles.

The other modes need multiple patterns because they're doing more complex institutional work — managing appearances (performative), protecting allies (defensive), constructing alternative epistemologies (conspiratorial), refusing evidence standing (denial). Reactionary mode just negates.

**Implication for 🔧 J:** The agent should not expect to find multiple structurally distinct reactionary patterns. When it detects reactionary denomination, the diagnostic question is not "which reactionary pattern?" but "which vehicle has the negation attached to?" The vehicle varies; the operation does not. Pattern #17 (denomination catastrophe) is the canonical expression because it captures the moment when the negation becomes permanent — the vehicle freezes the capital and forecloses recovery.

## Rejection Taxonomy Test Case Rulings

The rejection taxonomy (four categories defined in earlier 📓f work) was tested against four flagged cases from the scoring sessions.

### General Principle Established

**Category 3 rejections (instrumentalized subject framing) apply to axis proposals, not to events.** When the encoding detects instrumentalized subject framing within a scorable event, it scores the instrumentalization rather than rejecting the event. The instrumentalization becomes measurable data — the gap between the instrumentalized subject's Diatribe score (typically 0, pure experience) and the instrumentalizing framing's Diatribe score IS the instrumentalization.

The encoding scores the actual political object (executive power) and flags the divergence between claimed subject and actual object. If someone proposed scoring the impeachment on a "Ukraine policy" axis, *that axis* gets rejected under Category 3. The event itself remains scorable on the correct axis.

**Encoding instruction:** When claimed subject and actual political object diverge, score the actual object and flag the divergence in relational tags.

### Case 2 — Kansas/Ohio/Missouri Democratic Override (📓e2 Events 5, 6, 8)

**Question:** When institutional actors attempt to override or nullify democratic expression, does the encoding reject the institutional response as illegitimate discourse, or score it?

### Case 3 — Venezuelan Migrant as Instrumentalized Subject (📓e4)

## Oscillation Protocol Assessment

### Protocol as Specced
When an event is too unstable to score definitively, the encoding holds two scores simultaneously and flags the event as oscillating.

### Test Against Flagged Events

**📓e1 Event 10 — Iran strikes (2025–2026).** Z-axis oscillates: -0.70 (current — no exit strategy, escalation without authorization) with band toward +0.50 (if regime change produces stable outcome) or -0.95 (quagmire). Diatribe oscillates: 70 (current — performative glorification layered over genuine strategic substance) with band toward 45 (if strategic substance vindicated) or 85 (if spectacle is all there was). **Band width: Z = 145 points, Diatribe = 40 points.** Wide band reflects genuinely open outcome space.

**📓e4 Event 10 — Maduro capture (January 2026).** Z oscillates: -0.75 (current) with narrower range. Diatribe oscillates: 65–85. **Band width: Diatribe = 20 points.** Narrower band reflects structural constraint — the imperial template (Noriega → Maduro) limits the possibility space for fluid outcomes even though they're not impossible.

### Useful Output Test

Does the oscillation band tell the encoding something a single score wouldn't? **Yes.** Band width is itself diagnostic data:

- **Wide band** = event has genuine outcome uncertainty. Multiple structurally distinct endpoints are possible.
- **Narrow band at high end** = structural constraints make fluid outcomes unlikely. The template or institutional architecture limits the possibility space.

Iran's 40-point Diatribe band is wider than Maduro's 20-point band because Iran has more possible outcomes. The encoding should report band width alongside the dual scores.

### Other Entries Evaluated for Oscillation Flags

**📓e2 Event 8 (post-Dobbs field state, 2024–2026):** Scored as maximally unstable. NOT an oscillation case — it's a *field state* (active multi-front contestation) that generates a continuous stream of scores as individual battles resolve. Field states need a different protocol: not dual scores but a scoring stream that updates as component events resolve. **Flag for 🔧 J: field-state scoring mode needed, distinct from event scoring and oscillation scoring.**

**📓e1 Event 3 (JCPOA):** Was oscillating at time of passage. Has since resolved — Z migrated from +0.40 to -0.60, now stable. Demonstrates that oscillation flags are **temporal** — they expire when events resolve. Final score replaces dual scores.

**📓e2 Event 7 (Vance "childless cat ladies"):** Y-axis is "contested / unresolved" — the event's significance IS the fight over which axis it belongs on. NOT an oscillation case — this is *axis assignment instability*, which is closer to Category 4 of the rejection taxonomy (dialectically unripe) than to oscillation. The discourse hasn't resolved whether the event is fundamentally about cultural values or material conditions.

### Protocol Refinements

1. **Band width as diagnostic.** Report oscillation band width alongside dual scores. Width measures genuine uncertainty vs. structural determination.
2. **Temporal expiration.** Oscillation flags are not permanent. When the event resolves, the flag is retired and the final score is logged with a note on which end of the band materialized.
3. **Boundary: field states are not oscillation cases.** Field states require a scoring stream, not dual scores. Distinct protocol needed for 🔧 J.
4. **Boundary: axis assignment instability is a rejection taxonomy case (Category 4), not an oscillation case.** When the encoding can't determine which axis an event belongs on, it holds the event as dialectically unripe rather than oscillating.

**Verdict: Protocol works with refinements. No fundamental redesign needed.**
